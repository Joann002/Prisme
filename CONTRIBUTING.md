# Contribuer

1. Installe l’environnement avec `make setup`.
2. Vérifie tes changements avec `make lint test`.
3. Si tu changes l’évaluation, conserve le split temporel et indique la provenance, les valeurs de K et le nombre de cas dans la pull request.
4. Pour ajouter un domaine, suis le [tutoriel](docs/ajouter-un-domaine.md) et ajoute un petit test d’import avec des données fictives.

Les rapports du benchmark public acceptent les réplications documentées. Précise la version des données, les exclusions et les limites de comparaison. Les données brutes et les jetons d’accès restent hors du dépôt.

Consulte le [code de conduite](CODE_OF_CONDUCT.md) avant de participer.
