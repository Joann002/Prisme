# Prisme

Prisme relie des catalogues culturels par les descriptions, les tags et les préférences de profils lorsque ces signaux sont disponibles. La démo synthétique contient 98 entrées et cinq domaines.

Installe les dépendances verrouillées avec `make setup` depuis le dépôt, puis lance la démo avec `make demo` ou l’API avec `make api`.
